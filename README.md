# Vérifier si un point est dans une zone

Amine Hannachi — B2 — travail individuel.

## Contenu
- `tp/` : mes six carnets de TP (à vérifier et compléter avant le rendu).
- `projet/zones.ipynb` : mon projet de géométrie.

## Lancer
Ouvrir `projet/zones.ipynb` avec Jupyter ou JupyterLite et exécuter les cellules dans l’ordre avec Maj + Entrée. Le carnet utilise Python et matplotlib.

## Ce qu'on observe
Une zone en forme de L, des points verts et rouges, le calcul de son aire et une estimation par points aléatoires. Le creux du L doit être considéré comme extérieur.

## Limites
Les points sur les bords demandent un traitement particulier. L'estimation aléatoire varie selon le tirage.
