# Projet personnel — Recherche de racines

Ce projet recherche une solution approchée de l'équation x² - 2 = 0 avec la méthode de dichotomie.

On divise progressivement l'intervalle de recherche en deux. Le programme affiche la solution approchée, le nombre d'itérations et une vérification.

Exécution : `python projet_calcul/dichotomie.py`

C'est une première version, à compléter avec les notions du module.
